# 台股即時訊號分析

手機開啟的台股訊號分析網頁。伺服器集中向證交所公開報價抓資料並快取，盤中約每 5 秒一次、所有股票合併成一個請求；手機每秒讀取本伺服器，不會直接對證交所發請求。

- 修改追蹤股票：環境變數 `STOCKS`，例如 `0050,2330,2317`
- 美股、夜盤、匯率等盤前大盤數據需在網頁上手動輸入
- 部署：Render（`render.yaml`，新加坡機房，免費方案）

> 分數只是把常見技術訊號量化，不是預測，不構成投資建議。證交所 MIS 報價為非官方接口，可能延遲、變更或中斷。

## AI 選股

在 Render 服務的 Environment 加入下列其中一個金鑰即可啟用：

- `GEMINI_API_KEY`（aistudio.google.com 申請，有免費額度）。可用 `GEMINI_MODEL` 換模型（預設 `gemini-3.5-flash`）
- `ANTHROPIC_API_KEY`（console.anthropic.com 申請）。可用 `AI_MODEL` 換模型（預設 `claude-sonnet-5-5`）

兩個都設時預設用 Gemini，可用 `AI_PROVIDER=gemini|claude` 指定。全站每 3 分鐘最多分析一次以控制費用。

## 功能

- 手機上自行加入／移除自選股（每支手機各自記住，最多 20 檔；全站同時追蹤上限 30 檔）
- 技術指標：MA5／MA20／MA60、RSI(14)、KD(9)、MACD(12,26,9)，由證交所日 K 計算（上市股票）
- 盤中走勢小圖、價格提醒（網頁開著時跳出橫幅＋提示音）
- AI 選股會一併參考技術指標
- 全市場掃描：上市普通股全部評分（盤後用證交所全市場日成交＋三大法人；盤中對成交最活絡的約 180 檔每分鐘抓即時報價），AI 可從前 25 名候選中挑 5～8 檔
